What Does a CSS Minifier Do?

A CSS minifier removes unnecessary characters such as comments, extra whitespace, line breaks and spaces around CSS syntax while preserving the structure of the stylesheet.

This tool is designed for normal CSS stylesheets. Comments inside strings, URLs and other special CSS values are handled carefully so that valid CSS is less likely to be changed incorrectly.
