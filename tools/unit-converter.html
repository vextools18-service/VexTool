What is a unit converter?

A unit converter changes a measurement from one unit into another equivalent unit. Unit conversion is useful for everyday measurements, education, engineering, construction and many other applications.

Supported length units

The VexTools Unit Converter supports meters (m), kilometers (km), centimeters (cm), feet (ft) and inches (in).

How to use the Unit Converter

Enter the number you want to convert, select the unit you are converting from, select the unit you want to convert to, and click the Convert button. The converted value will appear instantly.

Common length conversions

You can use this tool for common conversions such as meters to feet, feet to meters, kilometers to meters, centimeters to inches and inches to centimeters.
