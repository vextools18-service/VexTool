What is a UUID?

UUID stands for Universally Unique Identifier. It is a 128-bit identifier commonly represented as a string of letters, numbers and hyphens. UUIDs are useful for identifying records, resources, objects and other items in software systems.

What is UUID v4?

UUID version 4 uses randomly generated values to create an identifier. This generator uses your browser's built-in cryptographic UUID generator when available.
