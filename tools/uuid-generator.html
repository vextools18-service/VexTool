Free UUID Generator

The VexTools UUID Generator creates random UUID version 4 identifiers directly in your browser. UUIDs can be useful for software development, databases, APIs, applications and other projects that require unique identifiers.

What is a UUID?

UUID stands for Universally Unique Identifier. It is a 128-bit identifier commonly represented as a string of letters, numbers and hyphens.

What is UUID v4?

UUID version 4 uses randomly generated values to create an identifier. This tool uses your browser's built-in cryptographic UUID generator when supported.
