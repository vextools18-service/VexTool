What is a Unix timestamp?

A Unix timestamp is a number representing a specific point in time. Unix time is commonly measured from January 1, 1970 UTC, making timestamps useful in programming, databases, APIs and websites.

How to convert a timestamp

Seconds vs milliseconds

Unix timestamps are commonly represented in either seconds or milliseconds. Shorter timestamp values are typically seconds, while longer values are typically milliseconds. VexTools automatically detects the format for convenient conversion.

Where are Unix timestamps used?

Unix timestamps are commonly used in software development, web applications, APIs, databases, logs and server systems to store and exchange time information consistently.
