Frequently Asked Questions

What is a random number generator?

A random number generator selects a number randomly from a specified range.

How do I generate a random number?

Enter a minimum and maximum value, then click the Generate Random Number button.

Can I use negative numbers?

Yes. Negative numbers can be used as either the minimum or maximum value.

What happens if the minimum is greater than the maximum?

VexTools automatically handles the range by using the smaller value as the minimum and the larger value as the maximum.

Is this random number generator free?

Yes. The VexTools Random Number Generator is free to use online.
